# ВЕТОП — Telegram-бот

Бот для сотрудников ОсОО «ВЕТОП»: накладные в PDF, склады по регионам,
долги контрагентов, журнал операций.

## Файлы

- `bot.py` — обработчики Telegram, диалог с Claude, подтверждения операций
- `db.py` — база SQLite: сотрудники, склады, остатки, клиенты, журнал
- `prices.py` — прайс-лист (пока в коде)
- `invoice_pdf.py` — PDF-накладная (и черновик с водяным знаком)

## Развёртывание на Railway

1. Переменные окружения: `TELEGRAM_TOKEN`, `ANTHROPIC_API_KEY`
   (необязательно: `CLAUDE_MODEL`, `DB_PATH`).
2. **Обязательно подключите Volume** к сервису с точкой монтирования `/data` —
   там живёт база `vetop.db`. Без Volume все остатки и долги будут стираться
   при каждом деплое.
3. Запуск — `Procfile`: `worker: python bot.py`.

## Роли

- **Админ** — все команды, видит все склады, получает уведомления о каждой операции.
- **Старший** (`/grant Имя`) — дополнительно может вносить приход и перемещение товара.
- **Сотрудник** — продаёт со своего склада (и складов, выданных через `/access`),
  видит свои остатки и долги.

## Как пользоваться

- Накладная: `Асан, Албенивер 200мл 1к` (бот подставит долг клиента из базы,
  покажет накладную на подтверждение, потом спишет остаток и пришлёт PDF).
- С другого склада: `со склада Ош: Асан, Албенивер 200мл 1к`.
- Черновик (ничего не меняет): `черновик: Асан, Албенивер 200мл 1к`.
- Оплата: `Асан приход 5000` или `/payment Асан 5000`.
- Приход товара (админ/старший): `Беке: Альтопен 100мл 2к`;
  перемещение: `с Ош на Каракол: Альтопен 100мл 1к`.
- Начальные остатки загружаются обычным приходом товара на каждый склад.
