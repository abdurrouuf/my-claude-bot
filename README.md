# ВЕТОП — Telegram-бот

Бот для сотрудников ОсОО «ВЕТОП»: накладные в PDF, склады по регионам,
долги контрагентов, лента операций в групповые чаты, журнал операций.

## Файлы

- `bot.py` — обработчики Telegram, диалог с Claude, подтверждения операций, лента
- `db.py` — база SQLite: сотрудники, склады, остатки, клиенты, журнал
- `prices.py` — прайс-лист (пока в коде)
- `invoice_pdf.py` — PDF-накладная (и черновик с водяным знаком)

## Развёртывание на Railway

1. Переменные окружения: `TELEGRAM_TOKEN`, `ANTHROPIC_API_KEY`
   (необязательно: `CLAUDE_MODEL`, `DB_PATH`).
   Экономия на API: по умолчанию используется `claude-sonnet-5` ($2/$10 за
   млн токенов по акции до 31.08.2026, затем $3/$15 — в 2.5 раза дешевле
   Opus), статичная часть промпта кэшируется (повторные чтения ~10% цены).
   Ещё дешевле: `CLAUDE_MODEL=claude-haiku-4-5` ($1/$5).
   Переходный период (завершён 13.08.2026): `TRANSITION_MODE` (по умолчанию
   `0` — все операции открыты; поставьте `1`, чтобы сотрудникам остались
   только черновики и вопросы о прайсе) и `DRAFT_WATERMARK` (по умолчанию
   `1` — черновики с пометкой ЧЕРНОВИК; поставьте `0`, чтобы убрать знак).
2. **Обязательно подключите Volume** к сервису с точкой монтирования `/data` —
   там живёт база `vetop.db`. Без Volume все остатки и долги будут стираться
   при каждом деплое.
3. Запуск — `Procfile`: `worker: python bot.py`.

## Структура складов

Склады: **Бишкек** (основной), **Кара-Балта**, **Каракол**, **Манас**.
У сотрудника есть склад по умолчанию (`/setwh Имя Склад`) и, при необходимости,
доступ к другим складам (`/access Имя Склад`). Жуми и Бека — Бишкек + Кара-Балта,
Данияр — Каракол, Азамат — Манас.

## Роли

- **Админ** — все команды, видит все склады, получает уведомления о каждой
  операции, единственный, кто подтверждает перемещения между складами.
- **Старший** (`/grant Имя`) — дополнительно может вносить приход товара извне.
- **Сотрудник** — продаёт со своего склада (и доступных), видит свои остатки
  и долги, пишет заявки на перемещение.

## Как пользоваться (в личке с ботом)

- Накладная: `Асан, Албенивер 200мл 1к` — бот подставит долг клиента из базы,
  покажет накладную на подтверждение, спишет остаток, пришлёт PDF.
- С другого склада: `со склада Кара-Балта: Асан, Албенивер 200мл 1к`.
- Черновик (ничего не меняет): `черновик: Асан, Албенивер 200мл 1к`.
- Оплата: `Асан приход 5000` или `/payment Асан 5000`.
- Перемещение (заявка, подтверждает админ): `с Бишкека на Каракол: Альтопен 100мл 1к`.
- Приход товара извне (админ/старший): `Беке: Альтопен 100мл 2к` или
  `на склад Манас: ...`. Начальные остатки загружаются так же.

## Лента операций в групповые чаты

Бот в группах не читает переписку — только публикует сводку каждой проведённой
операции (накладная, оплата, перемещение, отмена) по складам, привязанным к чату.

Настройка: добавьте бота в групповой чат и напишите там от имени админа:

```
/feed Бишкек Кара-Балта   ← в чате склада Бишкек
/feed Каракол             ← в чате Каракола
/feed Манас               ← в чате Манаса
```

Отключить: `/nofeed` в том же чате. Посмотреть привязки: `/warehouses` (в личке).
